Múltipla Escolha Dificuldade: Média

Qual a principal diferença entre um modelo CAD tradicional e um modelo BIM?

A

BIM utiliza apenas modelos 3D, enquanto CAD usa 2D.

check_circle B

BIM embute informações de dados nos elementos (paredes, portas), não apenas geometria.

C

Modelos BIM são sempre mais pesados para renderizar.

format_quote Fonte/Excert

"A transição do CAD para o BIM representa uma mudança do desenho para a modelagem da informação da construção, onde um elemento gráfico de 'parede' também contém dados sobre seu material, custo e transmitância térmica." - Capítulo 2, pg 45.
