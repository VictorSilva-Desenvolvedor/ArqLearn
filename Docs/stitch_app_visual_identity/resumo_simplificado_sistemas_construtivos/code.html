Alvenaria Estrutural vs. Vedação

Na estrutural, a própria parede suporta o peso. Na vedação (convencional), pilares e vigas assumem a carga, permitindo mais liberdade de reformas.

check_circle

Modulação

Essencial na alvenaria estrutural. O projeto arquitetônico deve ser pensado a partir do tamanho dos blocos (geralmente 14x19x29cm ou 19x19x39cm) para evitar cortes.

check_circle

Instalações Embutidas

Devem ser previstas no projeto de modulação para passarem por dentro dos blocos vazados, proibindo cortes posteriores na parede.

lightbulb Dica do Arquiteto

Sempre alinhe o projeto arquitetônico com os complementares (elétrico e hidrossanitário) antes de aprovar a modulação. Uma interferência não prevista pode comprometer a estrutura se um bloco precisar ser quebrado indevidamente na obra.
